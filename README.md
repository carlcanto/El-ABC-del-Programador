# El ABC del Programador

Presentación web para una charla-taller universitaria sobre **Git, GitHub, Docker y Linux**.

## Stack

- HTML5 + CSS3 + JavaScript Vanilla
- Sin frameworks ni librerías externas
- Google Fonts: Montserrat (títulos), Inter (cuerpo)

## Navegación

- **← ↑ / ↓ →** — diapositiva anterior / siguiente
- **Espacio** — siguiente diapositiva
- **Inicio / Fin** — primera / última diapositiva
- **P** — abre ventana de presentador
- **Rueda del mouse** — navegación
- **Touch swipe** — navegación en móvil

## Modo Presentador

Presiona **P** para abrir una ventana secundaria con:
- Vista previa del slide actual
- Vista previa del siguiente slide
- Cronómetro
- Notas privadas del presentador

Las notas se definen en el atributo `data-notes` de cada slide.

## Desarrollo local

Abre `index.html` en cualquier navegador. No requiere servidor.
